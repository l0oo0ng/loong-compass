# 安全报告 / Security reporting

不要在公开 Issue 中发布密钥、私人材料或可用凭证。使用仓库 Security 页的私密报告入口（若已启用）；不可用时仅提交不含敏感细节的联系请求，由维护者提供私密渠道。 / Do not disclose credentials or private material in public issues. Use private vulnerability reporting if enabled; otherwise request a private channel without sensitive details.

自动检查不等于完整安全审计。CodeQL 是否启用以仓库实际设置和运行记录为准；不改变许可证、可见性或购买服务。 / Automated checks are not a full security audit. CodeQL status follows actual repository settings and runs; no visibility or licensing changes are made.
